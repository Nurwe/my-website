# Personal Economics Website

A simple static website for an economics student portfolio.

## Files

- `index.html` — main website structure and content.
- `styles.css` — responsive styling for the page.
- `script.js` — small mobile menu behavior.

## Customize

1. Replace `Your Name` in `index.html` with your actual name.
2. Update the intro, experience, and writing examples to match your background.
3. Replace `youremail@example.com` with your real contact email.
4. Add or remove blog entries in the `Writings` section in `index.html`.

## Run locally

Open `index.html` in your browser.
